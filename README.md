# elsfk

俄罗斯方块 PWA — [在线游玩](https://unplage.github.io/elsfk/)

## 功能特性

- **SRS 旋转系统** + T-Spin 判定
- **Lock Delay**（500ms，15 次移动/旋转重置上限）
- **DAS/ARR** 可配置（默认 167ms / 33ms）
- **软降 20× 重力**（官方指南标准速度，非 20G 瞬落）
- **Hard Drop** 冲击波动画
- **多游戏模式**：经典、限时、Sprint（40行）、Ultra（2分钟）、马拉松、生存
- **个人统计 + 成就系统**
- **多主题皮肤**、音效增强
- **PWA 离线支持**

## 操作

| 按键 | 功能 |
|------|------|
| ← → | 左右移动（DAS/ARR） |
| ↓ | 软降（加速下落，+1 分/行） |
| ↑ | 旋转 |
| 空格 | Hard Drop（+2 分/行） |
| C | Hold |
| P | 暂停 |
| Esc | 设置 |
